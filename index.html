Paper Plane setup

One-time step so notifications work with Paper Plane closed. It signs Paper Plane's notifications up in CloudKit's test area; then you deploy them to the real one.

1. The access token (CloudKit Console)

  1. On icloud.developer.apple.com, open iCloud.com.turbo.paperplane → Tokens & Keys (or API Access) → API Tokens, and open your token (or make one with +).
  2. Set Sign In Callback to URL Redirect, with the URL https://turbocrackers.github.io/paperplane-setup/
  3. Allowed Origins: Any domain. Save, copy the token, and paste it here:

2. Sign in with your Apple ID

Any Apple ID works. Apple's sign-in page opens in this tab, then brings you back here.

3. Sign up the notifications (round 2)

Waiting for steps 1 and 2…

4. Then

  1. In the CloudKit Console: Deploy Schema Changes… → Deploy (even if it lists no changes).
  2. Close and reopen Paper Plane. Settings › Internet should say Push sign-up: saved.
  3. Delete the API token in the Console, and tell Claude so it can delete this page.
