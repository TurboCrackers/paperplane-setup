Paper Plane setup

One-time step so notifications work with Paper Plane closed. It signs Paper Plane's notifications up in CloudKit's test area; then you deploy them to the real one.

1. Make an access token (CloudKit Console)

  1. On icloud.developer.apple.com, open iCloud.com.turbo.paperplane.
  2. Go to Tokens & Keys (or API Access) → API Tokens → +.
  3. Name: setup page. Sign In Callback: postMessage. Allowed Origins: https://turbocrackers.github.io (or "Any domain").
  4. Save, copy the token, and paste it here:

2. Sign in with your Apple ID

Any Apple ID works. Allow the pop-up if Safari asks. If the pop-up says "Authentication Error": in the iPhone's Settings › Apps › Safari, turn off Prevent Cross-Site Tracking and Block Pop-ups for now, close the pop-up, reload this page and try again (turn them back on afterwards).

3. Sign up the notifications

Waiting for step 1…

4. Then

  1. In the CloudKit Console: Deploy Schema Changes… → Deploy (even if it lists no changes).
  2. Close and reopen Paper Plane. Settings › Internet should say Push sign-up: saved.
  3. Tell Claude, so it can delete this page and the token.
